한 번의 요청에 수만 건의 데이터 수집 안정화 및 비동기 처리 개선

이츠인 | 2026.02 ~ 2026.04 (3개월)

Description

FortiSIEM·PRTG 기반의 방화벽 월간 보고서 데이터 수집 과정에서 발생하던 데이터 누락과 외부 시스템 과부하 문제를 분석하고,
조회 쿼리·재시도 정책·비동기 동시성 제어를 개선하여 데이터 수집 안정성과 정합성을 높였습니다.

Key Contributions

  • 평균 부하 약 60%의 FortiSIEM 환경에서 조회·재시도 정책을 개선하여 데이터 누락 및 정합성 문제 해결
  • PRTG 요청별 응답 시간을 계측하여 과도한 비동기 요청·재시도가 HTTP 429와 자원 부하를 유발하는 병목 식별
  • Exponential Backoff·Jitter 적용 및 동시성 최대 3개 제한으로 429와 자원 부하 알람 해소
  • 월간 보고서 생성 시간을 평균 40분 → 15분으로 단축하여 처리시간 약 62.5% 개선

MySQL → PostgreSQL 데이터 마이그레이션 및 JWT 인증 고도화

이츠인 | 2026.02 ~ 2026.03 (2개월)

Description

스키마와 테이블 관계가 불완전한 레거시 환경에서 MySQL 운영 데이터를 PostgreSQL로 안전하게 이관하고,
Access Token 단독으로 구성된 기존 인증 방식을 Refresh Token 기반의 인증 구조로 고도화한 프로젝트입니다.

Key Contributions

  • PK·FK·제약조건과 연관관계가 불완전한 26개 레거시 테이블을 분석하고, 데이터 의존관계와 이관 순서를 수립하여 MySQL 운영 데이터를 PostgreSQL로 마이그레이션
  • SELECT·JOIN 기반으로 테이블 간 실제 데이터 관계를 검증하고, 이관 전후 데이터 누락 및 참조 관계를 점검하여 데이터 정합성 확보
  • Refresh Token 기반 인증 구조를 구현하고 Rotation·Blacklist·토큰 해시 저장·Secure Cookie를 적용하여, 로그인 유지 편의성을 개선하고 토큰 재사용 및 노출 위험 완화
